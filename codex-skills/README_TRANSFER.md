# Codex Skills Transfer Folder

This folder contains these skills:

- `binary-mask-stack`
- `nadph-phasor-trajectory`
- `tmrm-lgr5-nadph-analysis`
- `tmrm-nadph-analysis`
- `tmrm-nadph-percentile-plots`

## Install On Another Windows PC

1. Copy this whole folder to the other PC.
2. Open PowerShell in this folder.
3. Run:

```powershell
.\install_skills.ps1
```

The script copies the skill folders into:

```text
%USERPROFILE%\.codex\skills
```

Restart Codex after installing so it reloads the skills.
